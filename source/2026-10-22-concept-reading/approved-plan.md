# CEH 閱讀重規劃：一次完成一個重要概念

## 採用方向

依你的補充，**「一個重要概念」就是清單中的一個核心必學概念**：一次讀 DNS、一次讀 FTP、一次讀 SMB。DNS 的記錄、查詢與資訊揭露會放在同一次主題內連貫說明，不再拆成多個獨立任務。

全 CEH 採這個新節奏，先把 M04 路線排清楚。目標是讓每次都有明確範圍、能理解的成果，以及容易接續的下一步。

## 每次閱讀方式與完成條件

每次只開啟一個主題，依序完成：

1. **理解概念：** 用臺灣繁體中文說明用途、運作方式與重要英文術語。
2. **看一個具體例子：** 使用假想情境或既有安全範例，連結服務回應、可取得資訊、存取條件與防護措施。
3. **做一個小檢核：** 一題判斷題或一句自己的解釋，確認本次最重要的觀念。

回答有誤時，針對該觀念補充說明，再用一個不同例子確認；仍不清楚就保留續讀位置。這是新的閱讀檢核方式，取代閱讀時強制完成十題及三次複測的要求。正式題庫練習保留獨立紀錄。

**完成條件：** 已讀完本主題，且能正確解釋或判斷核心觀念。只閱讀尚未檢核，記為「已閱讀、理解待確認」；中途停止，記為「進行中」。

每次不附帶必交 Blog、完整報告或操作實驗。實際操作另行安排，閱讀完成與實作通過分開記錄。若當次容量不足，同一主題下次接續，不必重讀，也不直接跳下一項。

## M04 閱讀順序

保留你提供的十二個核心概念及順序；每列是一個閱讀任務。

| 次序 | 重要概念 | 本次要建立的理解 |
|---|---|---|
| 1 | Enumeration Concepts | 區分偵察、掃描、列舉，以及資訊取得與存取權限 |
| 2 | DNS Enumeration | 理解常見記錄、查詢結果與資訊揭露；認識 AXFR、Cache Snooping、DNSSEC 的界線 |
| 3 | FTP Enumeration | 理解服務回應、匿名登入與檔案權限各自能證明什麼 |
| 4 | SMB Enumeration | 理解共享資源、驗證、授權，以及 TCP 445 的判讀界線 |
| 5 | NetBIOS Enumeration | 理解名稱資訊、137–139 與現代 SMB 的關係 |
| 6 | SMTP Enumeration | 理解郵件服務如何回應，以及帳號資訊可能揭露的條件 |
| 7 | Unix/Linux User Enumeration | 理解使用者、群組、UID/GID 與權限 |
| 8 | NFS Enumeration | 理解 Export、掛載、身分對應與共享權限 |
| 9 | SNMP Enumeration | 理解 MIB、OID、Community String，以及版本與安全設定 |
| 10 | LDAP Enumeration | 理解目錄、DN、物件、屬性、群組與查詢權限 |
| 11 | RPC Enumeration | 理解遠端程序呼叫、介面與端點；辨識不同 RPC 系統的差異 |
| 12 | Enumeration Countermeasures | 將觀察證據連到風險、具體防護與驗證方式 |

防護觀念隨各主題介紹，第十二次再整合。

完成核心後，依序閱讀 **Telnet → TFTP → NTP → IPv6 → VoIP → IPsec → BGP**，一次一項。第一輪以能辨識用途、解釋資訊揭露及判斷風險為完成深度。AI 輔助列舉保留為選讀延伸。

十九項是教學分組；官方 v5.0 藍圖將 Enumeration 配置為七題，不提供這十九項各自的固定題數。[官方藍圖](https://cert.eccouncil.org/wp-content/uploads/2024/04/CEH-Exam-Blueprint-v5.pdf)

## 容量、紀錄與文件調整

- CEH／CEHP 合計每週最多 240 分鐘、上課日自學最多 25 分鐘，繼續作為容量上限；每次依實際可用時間閱讀。
- 原「六堂、約 10–12 小時」保留為來源中的估計，不作新排程。以實際閱讀與檢核耗時逐步估算。
- **600 題與 11/29 完成期限改為待重估。** 題庫保留供後續練習；未完成題量不轉成每日閱讀欠額。
- 每日 Blog 改為另行選擇的整理／發表活動。既有文章、答案、分數及實作證據完整保留。
- CEH repo 保存原文、採用決策、十九項閱讀目錄與學習紀錄；Planning 只更新路線入口、容量、目前主題與下一步。
- 更新現行計畫、教學入口及完成條件，明確標註舊要求的適用沿革，避免下次又自動恢復十題與 Blog 的閱讀門檻。
- 每次只記：主題、狀態、實際回答、需補充處、續讀位置。實際時間有回報才填。

## 驗收與開始位置

文件更新後，檢查現行入口均指向同一閱讀規則、十九項順序完整、歷史成績未變，並執行連結、空白及 Planning 驗證。

下一次從 **第 1 項：Enumeration Concepts** 開始：說清楚偵察、掃描與列舉的差異，用一個服務回應例子理解證據界線，最後做一個小檢核。完成後結束該次任務；下一次再讀 DNS。

本輪只完成規劃，尚未修改或發布檔案。小檢核證明的是當次概念理解；完整章節覆蓋、實作能力與考試準備度仍各自判定。
