# CEH M04｜什麼是 SMB（Server Message Block）？

一句話解釋：SMB 是一套讓不同電腦透過網路，共用資料夾、讀取檔案及傳送檔案的通訊規則（Protocol，協定）。

你可以把 SMB 想像成「公司的網路共用文件櫃」。

## 一、先從生活中的例子理解 SMB

假設你在一家公司上班，有三位員工：

- 小明：財務部，使用 Windows 電腦。
- 小華：行政部，使用 Windows 電腦。
- 小美：設計部，使用 Mac 電腦。

公司有一台專門存放檔案的電腦，稱為「檔案伺服器（File Server）」。

三位員工可以透過 SMB 與同一台檔案伺服器溝通，但不代表每個人都能讀取所有資料夾。

以前如果小明要把檔案交給小華，可能需要用 USB 隨身碟。

有了 SMB，只要電腦之間的網路連通，而且具有適當權限，小明就可以把檔案放進公司的共用資料夾，小華直接從自己的電腦讀取。

而且兩人不一定需要使用相同的作業系統。

SMB 就是讓這些電腦知道「如何向另一台電腦要求檔案，以及如何傳送檔案」的共同語言。

## 二、SMB 的運作原理是什麼？

假設檔案伺服器的 IP 位址是 `192.168.1.10`。

它提供一個名為 `Public` 的共用資料夾。

你在 Windows 檔案總管的網址列輸入：

```
\\192.168.1.10\Public
```

這段路徑包含三個概念：

| 內容 | 意思 |
| --- | --- |
| `192.168.1.10` | 檔案伺服器的 IP 位址 |
| `Public` | 共用資料夾名稱（Share Name） |
| `\\` | Windows 網路路徑使用的開頭格式 |

當你嘗試開啟資料夾時，通常會發生以下流程：

1. 建立網路連線

   你的電腦嘗試連線到檔案伺服器，現代 SMB 一般使用 TCP 445。
2. 協商通訊方式

   雙方協商可使用的 SMB 版本及相關安全功能。
3. 身分驗證（Authentication）

   伺服器確認你的身分，例如使用 Windows 帳號認證。
4. 檢查存取權限（Authorization）

   伺服器確認你能不能讀取或修改指定的資料夾與檔案。
5. 傳送資料

   權限允許時，你就能開啟、下載、儲存或修改檔案。

以上是簡化流程。實際系統可能重複使用既有登入工作階段，部分環境也允許訪客存取。

SMB 不只是「傳檔工具」。它還支援遠端檔案操作，例如列出目錄、建立檔案、重新命名、鎖定檔案等。

## 三、SMB 和 Samba、NAS 有什麼關係？

這三個名詞很容易搞混。

| 名詞 | 白話文 |
| --- | --- |
| SMB | 網路檔案共用的通訊規則 |
| Samba | 讓 Linux、Unix 等系統提供或使用 SMB 服務的軟體 |
| NAS | 專門提供網路儲存功能的設備，通常支援 SMB 等協定 |

例如，你買了一台 NAS 放在家裡，希望 Windows 筆電、MacBook 都能讀取 NAS 裡面的照片。

這時候 NAS 就可能利用 SMB 提供檔案共用服務。

SMB 是「溝通規則」，NAS 是「儲存設備」，Samba 是「實作這套規則的軟體」。

## 四、為什麼 SMB 對駭客與資安工程師很重要？

在 CEH 課程中，我們關心的不只是 SMB 能不能傳檔，還包括它可能透露什麼資訊。

例如，資安工程師掃描某台伺服器：

```
PORT      STATE
445/tcp   open
```

代表此次偵測到 TCP 445 開放，但還需要確認實際提供的協定服務。

接著透過合法測試帳號向 SMB 服務查詢共用資源，得到：

```
Public
Finance
HR
```

這個動作就叫做 SMB Enumeration（SMB 列舉）。

它只是查出伺服器有哪些共用資源，不代表能夠開啟其中所有檔案。

例如：

Public

允許讀取

Finance

測試讀取遭拒

HR

尚未測試

這三種狀態完全不同。

你必須區分「知道資源存在」、「成功讀取檔案」與「能夠修改檔案」。

SMB 的安全性也很重要。應使用受支援的現代 SMB 版本、設定適當權限，並且避免把 TCP 445 直接暴露在公開網際網路上。舊版 SMBv1 已不建議使用。

## 五、你可以自己試一次

如果你有兩台 Windows 電腦，而且都在同一個允許互相連線的網路，可以做一個簡單練習。

在第一台電腦建立 `Training` 資料夾，利用 Windows 的資料夾內容 → 共用功能，授予指定測試帳號適當的讀取權限。

在第二台電腦的檔案總管輸入：

```
\\第一台電腦的IP\Training
```

如果網路、防火牆、共用設定與帳號權限都正確，你就能看到第一台電腦所分享的檔案。

這是 SMB 最直觀的用途，也是理解 SMB 列舉與權限檢查的起點。
