## Distinguish target, channel and pretext

Phishing uses deceptive messages to induce actions. Spear phishing is targeted; whaling targets senior decision-makers. Vishing is voice delivery and smishing is SMS delivery. A caller pretending to be a manager can simultaneously be impersonation, pretexting and vishing. The question must specify which classification level it asks for. Caller-ID spoofing provides a false displayed identity, not proof the call comes from that institution.

Clone phishing reuses a genuine earlier message while changing a link/attachment. Search-engine phishing promotes a fake destination in search results; pharming instead manipulates a resolution/routing path to redirect intended visits. Elicitation extracts information through guided casual conversation. Baiting offers an attractive object or benefit. A hoax is a false warning even when no payload is attached. A quid-pro-quo pretext offers an exchange; urgency and authority are persuasion cues rather than standalone delivery protocols.

## Physical and digital evidence

Tailgating follows someone through an admission barrier. Some sources reserve piggybacking for knowingly assisted entry, but usage varies. Technician impersonation is not automatically tailgating unless following occurs. Shoulder surfing observes screens/typing; dumpster diving collects discarded information. A labeled USB is a lure, while insertion and code execution are later events that need their own evidence.

Compare visible link text with the actual destination and redirect chain. An unrelated shortened link is a warning sign, not a complete forensic verdict. Familiar branding, a signature footer or a trusted display name are weak identity evidence. Verify requests through a separately known channel and protect the sensitive action, not merely the initial login. Training, process checks, least privilege and phishing-resistant authentication reinforce each other.

Example: an HR caller claiming to be a manager asks urgently for payroll records. Log the claimed role, channel, requested data and independent verification result. A statement that an approach is most effective or undetectable remains an untested claim; these notes prepare recognition rather than conduct a campaign.
