## Classify behavior on separate axes

A Trojan disguises its purpose; a worm replicates autonomously; ransomware extorts through encryption or other harm; spyware collects information; a RAT supplies remote control; bot agents execute coordinated remote instructions. These properties can coexist. A worm can deliver a RAT or a bot agent. A wrapper bundles code with a functioning program, a dropper places another payload locally and a downloader retrieves it. One package can have more than one role. PUAs describe unwanted behavior, not proof that unexplained outbound traffic is harmless.

Polymorphism changes representation, often including an encryption/decryptor wrapper. Metamorphism rewrites the program's structure while preserving behavior. A stealth virus hides changes through system-call interference. A trigger/date characterizes a logic bomb independently of representation. Dynamic code changes and evasive behavior do not by themselves prove AI use. An inference-time adversarial example differs from poisoning/backdooring training data.

## Execution, persistence and analysis

Fileless describes execution that need not drop a conventional executable; PowerShell, memory and trusted tools may still leave script, process, network and event evidence. HTML smuggling reconstructs content in the browser rather than transferring a plainly inspectable file in one network response. BITS can be abused for background transfer, but its jobs, owners and destinations remain observable and are not identical to Windows Update. Keylogging may occur in hardware, a user process, a driver or just one browser form.

Static analysis inspects bytes and structure without running the sample. Dynamic analysis observes execution in an isolated controlled environment. A PDF containing /JavaScript and /OpenAction is a lead: inspect streams/actions and behavior before claiming exploitation. A hash match supports artifact identity; a hash mismatch alone does not identify a malware family.

Rootkits hide privileged activity at different layers: user/kernel, boot chain, firmware or hypervisor. An OS reinstall can miss firmware persistence. Preserve evidence, coordinate containment and restore from a trusted baseline appropriate to the affected layer; rotate exposed credentials and investigate re-entry.

Example: a sample spreads by itself, installs a hidden remote controller and waits for synchronized instructions. Record autonomous propagation, concealed installation and botnet control as separate properties. That gives a more useful explanation than forcing every observation into one exclusive malware label.
