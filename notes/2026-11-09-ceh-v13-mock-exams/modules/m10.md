## Identify the exhausted resource

DoS is an availability outcome. DDoS distributes participating sources; reflection sends requests with the victim's source address to third-party responders, and amplification increases reply volume. A botnet is a control structure rather than a packet type. Ransom DDoS adds an extortion demand and differs from reflected DRDoS. Pulsed traffic describes a temporal pattern.

A SYN flood pressures half-open connection state. An HTTP flood consumes application work. Slowloris holds incomplete requests/connections with little bandwidth. UDP or ICMP floods may saturate packet processing or links. Teardrop and classic Ping of Death exploit vulnerable fragment/reassembly behavior rather than merely a high request count. A SQL flaw can make a database do expensive work, but distributed SQL injection is not inherently the hardest availability attack.

## Match mitigation to the bottleneck

Rate limits cap work per interval/identity; shared users and distributed attackers complicate thresholds. Load balancing distributes requests across finite capacity. Graceful degradation sheds lower-priority functionality to preserve critical paths. WAF/application controls can filter HTTP behavior; they cannot restore an already saturated access link. Upstream scrubbing/provider coordination handles volume before it reaches that link. A multivector incident needs layered capacity, protocol and application controls with tested routing and legitimate-client behavior.

Detection can use known signatures, traffic profiles, change-point statistics or wavelet/signal analysis. These methods trade false alarms, coverage and delay; none mathematically guarantees the exact instant an attack began from noisy observations.

## Verified case and scope

Google reported the 398-million-rps HTTP/2 Rapid Reset campaign in October 2023, describing repeated stream creation/cancellation. Its technical report says it did not cause outages. Preserve that mechanism/date instead of adopting the source's generic GET/POST label or claimed few-minute service interruption. The figure is historical, not a current largest-attack claim.

Example: the link is saturated by reflected DNS replies while a slow-request pattern also affects the origin. Upstream filtering addresses the volume; origin/proxy request deadlines and connection controls address slow requests.
