## Credentials and identity material

Distinguish collection from guessing and authentication reuse. hashdump extracts local password-verifier material when privileges permit; a cracking tool then tests candidate passwords. Brute force enumerates a defined space. A dictionary chooses candidates, rules mutate them, a combinator joins input words and PRINCE builds variable chains from one input list. Salts prevent reusable cross-user precomputation; a slow password KDF increases each guess's cost. A long list is not a measured cracking success.

Credential stuffing replays previously obtained username/password pairs. Spraying tries a few passwords across many accounts. Account-focused brute force concentrates attempts on one/few users. Captured NTLM challenge-response material is different from the underlying NT hash. Pass-the-hash uses compatible hash-derived authentication material; pass-the-ticket reuses Kerberos tickets. Kerberoasting, relay and offline password recovery have distinct prerequisites.

## Crossing privilege boundaries

Vertical escalation moves to a higher authority tier. Horizontal access reaches another same-tier identity/resource; lateral movement crosses systems. DLL search-order hijacking executes with the victim process's privileges and only escalates if those privileges exceed the attacker's. UAC bypass depends on token/account and system configuration. TOCTOU occurs when a checked resource changes before use; atomic operations and securely opened handles avoid the gap. Buffer overflows describe memory-boundary writes; executable control depends on memory layout and mitigations.

## Persistence and evidence

Services, scheduled tasks, registry Run keys and startup locations can all relaunch code. Reboot survival alone does not identify which was used; Run keys normally act at logon. Review actual task triggers, service settings, key paths, process ancestry and file integrity. Trusted executable hashes help identify modified utilities but need a trustworthy baseline. Clearing local event logs is an action defenders can also detect, and remote copies may survive.

Example: an application loads an attacker-writable DLL as a standard user. That supports DLL hijacking, but privilege escalation remains unproven until an elevated security context is demonstrated. The same evidence discipline applies to a relayed authentication or newly issued certificate: establish the actual permission granted rather than assume domain administration.
