# Day 1-3 Learning Package Rule

## Purpose

This repo treats the Day 1-3 learning package as the standard shape for compact
CEH / CEHP study packets. The package turns official scope, assessment
governance, weak-topic repair, and CEH exam focus into one usable learner
bundle.

## Rule

Every complete learning packet should include:

- learner-facing study guide;
- worksheet;
- pretest question file;
- separate pretest answer key;
- posttest question file;
- separate posttest answer key;
- CEH exam-focus and missing-advice file;
- traceability map;
- daily closeout record.

## Required Connections

| Repo file | Connection |

## Quality Gate

Before a packet is considered ready:

- question files and answer keys are separate;
- every item maps to official CEH / CEHP scope;
- critical safety items affect readiness status;
- the packet names missing-but-important advice, not only covered topics;
- the closeout produces `pass`, `review`, or `activation_needed`;
- no private identifiers, credentials, real target details, or unauthorized lab
  instructions are included.

## Day 4+ Extension

Use this Day 1-3 packet shape for later module packets. Day 4 starts with M01
Ethical Hacking Introduction and must include an authorization/scope note,
versioned ten-item choice posttest, answer key, weak-topic repair action, and closeout record.
