# 逐場景導演工作流程 v1.0

採納日期：2026-10-21（Asia/Taipei）。狀態：**implemented — 文件與模板**；引擎自動轉換、創作審閱強制檢查與新運鏡能力為 **proposed**。本次未製作新版影片。決策來源見 [採納紀錄](DIRECTOR_LED_ADOPTION.md)。

## 分工與適用範圍

使用者決定教學內容、章節、案例、結論與英文講稿；助理設計圖示、構圖、動作、運鏡與轉場。先完成全片提案，再由使用者一次審閱、逐場確認。使用者可用自然語言提出修改，無須提供座標或程式碼。

FIRST PRINCIPLE：稀缺資源是使用者的創作審閱時間與重製成本。CEH repository 持有內容、規格、決策與證據；本機 Videos workspace 持有大型媒體。Planning 延續既有狀態與定位角色，本次不新增排程或個人工作時數。下一個製作關卡是具名版本的內容與分鏡確認；此文件的採納不等於任何新分鏡已確認。

此流程適用未來製作及明確啟動的改版。既有 M11 保持原本的製作、QA 與人工驗收狀態；不追溯補造創作核准紀錄。系列藝術方向與 [初版通則](INITIAL_SERIES_STANDARD.md)、[英文時間政策](AUDIO_TIMING_POLICY.md) 繼續生效。

## 使用順序

1. 使用 [內容簡報](templates/director-led/BRIEF.template.md) 提供目標、範圍、來源及講稿。只有主題時，助理集中提出內容缺口與候選大綱；候選內容維持待採納，不直接進入製作。
2. 指定單一講稿來源。既有模組引用其 canonical 檔案、場景 ID、段落及版本／SHA-256；新模組在簡報中指定唯一講稿檔。分鏡只引用講稿並摘錄觸發短語，不建立第二份可獨立修改的全文。
3. 助理按 [分鏡模板](templates/director-led/STORYBOARD.template.md) 完成全片，包含教學場景、八題測驗與結尾。內容缺口、技術疑慮及替代方案集中列出。先提供全片總覽，再呈現逐場細節，不按每一場反覆要求回覆。
4. 使用者透過 [審閱與修改表](templates/director-led/REVIEW.template.md) 對每場確認或提出修改。全片確認可使用明確版本與完整場景清單；有例外時逐一列出。沒有回覆的場景仍為 pending。
5. 確認後依使用者指定的下一階段交接：靜態預覽、動態預覽或正式製作。製作人員將核准來源轉入現有引擎輸入，核對文字、場景與分鏡 ID 對照並記錄差異。**本次未新增模板到引擎的自動編譯器，也未更動 CLI。**
6. 未來實作遵循代表場景檢查 → 受影響範圍修正 → 全片 QA → 成片驗收。保留已確認且未受影響的場景，實際輸入變更依現有依賴圖處理。

[Prompt 指南](DIRECTOR_PROMPTS.md) 可直接複製；[M11 S06 範例](templates/director-led/M11_S06.example.md) 展示如何把畫面意圖寫清楚。

## 分鏡必備資訊與視覺語彙

每個場景有穩定 scene ID；每個鏡頭有 shot ID。必填教學成果、講稿引用、事實／來源、畫面文字、素材身分、元素關係、動作、焦點、運鏡、轉場、旁白觸發點、限制、驗收方式與可行性狀態。重新排序保留 ID，刪除記錄 retired，新增另給 ID；交接時對照現有引擎的 presentation ID。

| 表現方式 | 適用意圖 | 必須說清楚 |
| --- | --- | --- |
| 圖示與角色互動 | 誰操作什麼、誰作出決定 | 主體、動作、物件與權限邊界 |
| 拓樸／封包流程 | 關係、傳遞與受阻位置 | 節點、方向、連接埠、成功／失敗 |
| 時間線／狀態變化 | 事件先後與生命週期 | 前後狀態、事件及時間意義 |
| 平行比較 | 差異、獨立條件、修正前後 | 比較維度；避免以箭頭暗示不存在的因果 |
| 證據展示 | 從觀察推導有限結論 | 觀察、解釋、限制；數值與標籤來源 |
| 卡片／文字 | 定義、摘要、選項 | 閱讀優先級與文字量，依內容選擇數量 |

每場的元素、段落及鏡頭數依教學需要決定。現有 M11 `build_source.py` 的三段／三節點限制仍存在；超出限制的提案必須標記需要工程調整，不宣稱模板已解除引擎限制。

運鏡先指定教學目的與目標，再選全景、聚焦、平移跟隨或回到總覽。時間先引用講稿短語，估算秒數標為 estimated；正式時間取自 measured PCM／對齊資料。動作與鏡頭的持續時間、easing 引用現有 tokens；新值列成提案，待具體畫面驗證。標題與字幕保留固定區域，圖示保持比例，連線跟隨實際 anchors。每個關鍵狀態必須可從絕對時間直接重建。

既有 SVG、圖示、流程／比較與依旁白揭露可沿用；鏡頭語意的自動編譯、完整導演介面及新的 focus/pan 路徑仍待實作驗證。Figma 可提供參考與素材規格，並非此流程的必要服務。

## 創作確認與修改影響

內容與畫面分別記錄 `pending / changes_requested / approved`。approved 必須有使用者實際回覆、版本、場景範圍及講稿／分鏡來源身分；助理不得自行代填確認。這些是文件工作流程狀態，與 HyperFrames 的 `outline / built / animated` 建置狀態分開，也尚未成為新的引擎強制 gate。

| 修改 | 需重新確認 | 後續可能受影響的製作 |
| --- | --- | --- |
| 論點、講稿、選項或答案 | 該場內容；相關畫面與錨點 | 變更語音片段、對齊、字幕、場景與下游組裝 |
| 元素關係、鏡頭順序、焦點或運鏡意圖 | 該場畫面；涉及語意時也確認內容 | 該場視覺、所屬章節及相關 QA；講稿未變可驗證重用 PCM |
| 共用元件改變可見結果 | 所有實際受影響場景 | 先代表場景，通過後才擴大 QA |
| 修復實作以符合已確認規格 | 記錄差異；意圖未變可沿用確認 | 受影響技術檢查 |
| 文件定位或封裝 | 除非改變內容，既有確認保留 | 對應文件／封裝檢查 |

實際重用以現有來源雜湊、輸出與 gate 為準；表格不保證任一編輯必然不需重跑。審閱等待、修改、首次製作、例行製作、失敗重跑與交付分開記帳；本次不宣稱已量得縮時效果。

## 保留契約與驗收

- M04 暖紙張風格、原始 Tally／Northstar、核准字體與素材 provenance；新增素材須具名審查。
- Kokoro af_heart、en-US、baseline 0.73；spoken PCM 恰好一次 atempo=1.4。畫面／動畫 1×，音樂關閉，1920×1080、30 FPS。
- 48 kHz stereo：開場 14,400、句間 14,400、結尾 24,000 audio frames；章節邊界是既有結尾加下一場開頭，共 38,400 frames（0.8 秒），不另外插入一段。影格對齊 padding 獨立記帳。
- 八題各完整朗讀題幹與 A–D，再插入 48,000 zero-valued PCM frames；合計 384,000。靜音中不出現字幕或答案，結束後才揭露與朗讀解析。AAC 殘留另行報告。
- 新／重設場景安全區 x=134.4..1785.6、y=86.4..993.6；唯一既有例外 LEGACY-M10-SUBTITLE-001 僅限凍結 M10 optimization-v1 S01–S58。M11 無例外。此流程不新增例外。
- 使用者創作確認、幾何／seek／截圖測試、成片影音驗證與人工觀看各有紀錄；新基線須實際檢視，測試失敗不自動更新 golden。

文件驗收：模板欄位齊全、範例引用可追溯、確認狀態誠實、相對連結存在、`git diff --check` 通過。文件驗收不代表新運鏡、轉換器或成片已測試。證據記錄於 [採納紀錄](DIRECTOR_LED_ADOPTION.md)。
