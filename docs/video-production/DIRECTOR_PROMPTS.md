# 導演模式 Prompt 使用指南

依 [逐場景導演通則](DIRECTOR_LED_WORKFLOW.md) 使用。你決定內容與講稿，我設計畫面與運鏡；全片一次交付審閱，每場保留決定。以下均為可複製範本，填寫與送出後才構成該次指令。

## 只有主題，尚未整理內容

```text
我想製作 CEH〔模組與主題〕的 English Masterclass。
請先協助我釐清觀眾、學習成果、必講內容、章節與來源。
你可以提供候選方向，但由我選定內容；缺口請集中詢問。
目前先做內容規劃，不生成正式語音或渲染影片。
```

## 已有內容，開始設計全片

```text
請依 CEH 逐場景導演流程規劃影片。
主題：
觀眾與先備知識：
看完必須理解或能做到：
必講內容：
排除內容：
章節與英文講稿來源／版本：
參考來源與指定案例：
希望的視覺表現：
長度期待：

內容與講稿由我決定，請你設計圖示、構圖、動作、運鏡與轉場。
內容有缺口時，集中列出問題與建議；建議待我選定後納入。
保留現有系列風格、字體、角色、英文旁白與時間規範。
請提供全片總覽、逐場分鏡及審閱表，讓我一次審閱全片。
每場列出教學目的、講稿引用、圖示關係、視覺焦點、
旁白觸發點、運鏡理由、驗收方式及實作可行性。
先完成規劃；正式語音與渲染等待具名版本及階段授權。
```

## 指定單場表現

```text
請設計 M11 S06「Rotate at the boundary」的分鏡。
沿用現有英文講稿，不修改內容。
讓觀眾看懂登入前識別碼、登入後新識別碼與舊識別碼失效的關係。
使用核准的瀏覽器、伺服器與票券圖示。
先建立全景；講到新識別碼時聚焦交換；
最後回到全景，呈現舊識別碼被拒絕與新識別碼的合法請求。
字幕固定，每次移動說明教學目的。
列出鏡頭順序、對應旁白、動作及需要額外工程驗證的部分。
這次只交付分鏡提案。
```

## 修改分鏡或成片

```text
修改版本：
場景／鏡頭 ID：
成片時間碼（尚無成片可略）：
目前問題：
希望觀眾注意到：
希望如何改變：
必須保留：

列出前後差異，說明是否影響講稿、旁白、時長、其他場景及 QA。
先更新受影響分鏡，保留其他已確認內容。
若只調整畫面，請驗證是否可沿用原語音，不為預覽重新生成全片音訊。
```

## 確認具名版本與下一階段

```text
我確認分鏡版本〔版本／來源身分〕的〔完整場景清單〕，
包含其引用的講稿、畫面關係與運鏡意圖。
待修改或尚未確認的場景：〔清單及理由，沒有則填無〕。
本次授權的下一階段：〔靜態預覽／動態預覽／正式製作〕。
只執行上述範圍；若需要改變已確認內容或畫面意圖，先提出具體差異。
```

你可以說「整版除了 S06 都確認」，但需指明版本且該版有完整場景清單。只說「看起來不錯」不會被擴張為未展示場景或下一階段的授權。

## 描述運鏡的小抄

使用「何時 → 看哪裡 → 看懂什麼 → 如何回到脈絡」即可。例如：「講到撤銷時，聚焦伺服器的失效紀錄，讓觀眾理解是伺服器拒絕舊識別碼，再拉回整體請求流程。」畫面上的數字、標籤與結論仍需來源。精確座標、縮放值及動畫曲線由既有設計 tokens 和實作驗證決定。
