# Instructor key — M01–M08, choice v0.2.0

Instructor-only: withhold this file until a formal original set is scored.

tag. Explain why the selected proposition follows from the scenario and why
the learner's selected distractor does not. Remediation uses new scenarios, not
shuffled versions of these questions.

[Nmap connect scan](https://nmap.org/book/man-port-scanning-techniques.html);

[Microsoft MS17-010](https://learn.microsoft.com/en-us/security-updates/securitybulletins/2017/ms17-010).
The scenarios are original and hypothetical. Source links support mechanisms,
not claims of a completed learner action.
