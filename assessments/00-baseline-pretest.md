# Baseline Pretest

## Instructions

Take this before studying with a closed-book setup. The goal is to locate weak
topics and choose the first repair modules.

- Timebox: `45` minutes.
- Answer format: choose one answer for multiple-choice questions; write short
  answers in `1-3` sentences.
- Scoring:
  - `32-40`: strong baseline, focus on CEHP practical review.
  - `22-31`: usable baseline, repair weak CEH modules before class.
  - `0-21`: start with vocabulary and defensive concepts before tools.

## Multiple Choice

   - A. user verification paths and technical controls
