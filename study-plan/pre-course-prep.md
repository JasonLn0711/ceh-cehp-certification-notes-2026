# Pre-Course Prep Plan

## Objective

Reach the target CEH13-AI class on `2026-10-12` through one integrated,
historical-incident side project per week across all twenty modules and nine
UUU skill outcomes. The course deepens that executable foundation through
instructor guidance and the authorized EC-Council lab environment.

## Rules

- Advance one bounded weekly incident project: attempt first, preserve the first
  blocker, research it, apply the result, rerun, and test acceptance.
- Map each module to that execution evidence, a concept/evidence/scope note,
  and an eight-item closed-book diagnostic posttest.
- Repair confirmed weak topics first and retest every module below `pass`.
- Use only `official_primary` or `licensed_supporting` sources from
  `curriculum/important-references.md`.
- Treat the registered EC-Council lab as the official practical-depth path.
  Representative safe exercises establish pre-class readiness without claiming
  completion of all official labs.
- Keep the note system compact before class and expand only from official
  course needs.

### Weekly Project Evidence Contract

Each weekly project is accepted only after the learner has produced:

1. one declared outcome, scope, and executable acceptance check;
2. one real authorized attempt with commands, output, or an exact blocker;
3. one focused research note answering that blocker or a current validation
   question;
4. one applied correction and rerun;
5. one closed-book explanation and the mapped scored posttests;
6. one locator in the weekly project index and readiness dashboard.

Prompts, prepared exercises, question files, and tutor guidance remain
`planned` until Jason completes the learner work.
